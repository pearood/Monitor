系统亮点

官网不是孤立页面，而是围绕当前项目的真实能力组织的对外分发入口。

在线学习状态感知

学生端支持实时专注度检测、手机检测、姿态判断和详细数据分析，不再只是简单演示页面。

教师端班级管理

教师可创建班级、生成班级码、查看学生在线状态和实时看板，形成班级管理闭环。

本地智能助手

小睿支持离线语音识别与本地千问控制，能完成页面控制、状态播报和辅助问答。

上线方式

推荐采用 Nginx 托管站点、反向代理后端的结构，这样网站和云端接口可以稳定共存。

推荐部署步骤

  1. 将打包后的安装包复制到站点的 downloads 目录。
  2. 将后端服务改为仅监听 127.0.0.1:8000。
  3. 使用 Nginx 托管本页面所在目录，并将 /api 和 /health 代理到 FastAPI。
  4. 重启 Nginx 与后端服务，公网即同时提供下载页和接口能力。
